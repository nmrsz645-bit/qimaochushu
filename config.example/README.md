# 本地配置示例

此目录只用于说明，不能存放真实密钥或真实链接。

首次启动后，推荐在桌面管理器的“配置”页面填写。软件默认会在本机 `config/` 目录读取以下文件：

- `平台链接.txt`：七猫书库页面完整链接。
- `企业微信接口.txt`：企业微信机器人 Webhook。
- `飞书api.txt`：飞书应用凭据，按软件支持格式填写。
- `出书完成表格.txt`：飞书 Sheets 链接。
- `豆包链接.txt`：如启用豆包流程时使用。
- `DeepSeek接口.txt`：DeepSeek/DashScope API Key。

另外需要根据实际使用情况准备：

- `充值模板/`：充值模板 TXT 文件。
- `违禁词.txt`：每行一个违禁词。
- `小说可移动/`：章节正文输出目录。
- `七猫出书/`：软件专属 Chrome 登录资料目录，由程序创建。

这些文件和目录均已被 `.gitignore` 排除，不能上传到 GitHub。
